实验准备

- **设备**：带 PyCharm 的电脑（建议用 PyCharm Community Edition）。

- 软件和库：

  - Python 3.x（PyCharm 自带或单独安装）。

  - 需要的库：scikit-learn, pandas, numpy, matplotlib, graphviz。

  - 安装步骤：

    1. 打开 PyCharm，点击 `File > Settings > Project > Python Interpreter`。

    2. 点击 `+` 号，搜索并安装：scikit-learn, pandas, numpy, matplotlib, pydotplus。

    3. 安装 graphviz：

       - Windows：下载 graphviz（https://graphviz.org/download/），安装后添加环境变量（老师会提供指南）。

       - macOS/Linux：用 `pip install graphviz` 或系统包管理器安装。

    4. 实验前运行老师提供的测试代码，确保环境没问题！

- 数据集：


    - 选项1：自己设计数据集（推荐“校园活动参与预测”，100 条记录，4-6 个特征，具体见步骤 2）。
    
    - 选项2：从中国数据网站下载数据集。以下是推荐的网站，适合下载小型、适合决策树实验的 CSV 数据集：
    
      - 和鲸社区：https://www.kesci.com  
    
        提供分类、回归等机器学习数据集，如房价预测、商品评论分类等。注册后可下载 CSV 文件。
    
      - 阿里云天池：https://tianchi.aliyun.com/dataset  
    
        包含零售、医疗、交通等领域的数据集，部分小型数据集适合初学者，需注册。
    
      - 中国国家数据：http://data.stats.gov.cn  
    
        提供统计数据，如人口、经济等，部分可导出为 CSV，适合简单分类任务。
    
      - 中国开放数据平台：https://www.opendata.cn  
    
        包含城市、交通、环境等数据，部分免费下载，需筛选小型数据集。

  - 要求：

    - 数据集需包含至少 100 条记录，4-6 个特征，至少一个分类目标变量（比如“是/否”或“类别 A/B/C”）。

    - 如果下载，优先选 CSV 格式，方便用 pandas 读取。

    - 报告里要说明数据集来源（自己设计或网站名称+链接）和选择理由。

实验步骤

 1. 热身：复习决策树知识

  - 阅读的“决策树基础知识”PDF（1信息增益、基尼指数、过拟合等）。

  - 在实验报告里回答两个问题：

    1. 用自己的话解释“信息增益”和“基尼指数”的区别？（100 字以内）

    2. 根据你的数据集，举一个可能的决策树分裂条件（比如“活动在周末”或“价格 > 50元”），并说说为什么选它？

- 提示：

  - 用自己的语言写，结合数据集特点，答案越独特越好！

2. 准备数据：设计或下载数据集

-  - 根据你选择的选项，准备数据集：

    - 选项1：自己设计数据集（校园活动参与预测）：

      - 主题：预测一个人会不会参加校园活动（比如讲座、派对、公益活动）。

      - 要求：

        - 至少 100 条记录，4-6 个特征。

        - 特征例子：

          - 学生年级（大一/大二/大三/大四）

          - 是否为社团成员（是/否）

          - 活动类型（学术/娱乐/公益）

          - 活动时间（工作日/周末）

          - 天气（晴/雨/阴）

          - 目标：是否参加（是/否）

        - 至少有一个数值特征（比如“活动距离公里数”）和一个分类特征（比如“活动类型”）。

        - 用 Excel 手动输入，或在 PyCharm 用 numpy.random 生成，保存为 CSV 文件（比如 `activity_data.csv`）。

      - 报告里写什么：

        - 每个特征的含义，为什么选它？

        - 你有没有加“随机错误”（比如填错几条数据）？为什么？

      - 提示：

        - 发挥创意！加个独特特征（比如“当天心情”），让数据集与众不同。

    - 选项2：下载数据集：

      - 从上面推荐的中国数据网站选一个数据集（推荐和鲸社区或天池的小型分类数据集）。

      - 确保数据集满足要求（100+ 条记录，4-6 个特征，含分类目标）。

      - 在 PyCharm 里做探索性数据分析（EDA）：

        - 用 pandas 计算每个特征的均值和方差。

        - 用 matplotlib 画一个特征的分布图（比如直方图或箱线图）。

      - 把数据集随机分成训练集（70%）和测试集（30%），设置随机种子（比如 `random_state=你的学号后4位`）。

      - 报告里写什么：

        - 数据集来源（网站名称+链接），为什么选它？

        - 根据 EDA，你觉得哪个特征可能对分类最重要？为什么？

        - 放上分布图，说明你的观察。

      - 提示：

        - 检查 CSV 文件格式，必要时清理数据（删除缺失值或无关列）。

        - 保存图表为图片（`plt.savefig('histogram.png')`）。

  - 通用要求：

    - 用 `pd.read_csv('your_data.csv')` 读取数据，检查格式。

    - 确保数据适合决策树（有明确的分类目标）。

3. 建决策树模型

- 做什么：

  1. 写代码训练模型：

     - 在 PyCharm 新建一个 `.py` 文件（比如 `decision_tree.py`）。

     - 用 scikit-learn 的 `DecisionTreeClassifier` 建模型。

     - 试试不同的设置：

       - 最大深度（`max_depth`）：至少试 3 和 5。

       - 分裂标准（`criterion`）：试 “gini” 和 “entropy”。

     - 用训练集训练模型，算训练集和测试集的准确率（用 `accuracy_score`）。

  2. 画决策树：

     - 用 `export_graphviz`（配合 pydotplus）或 `plot_tree` 把决策树画出来。

     - 保存为图片（比如 `tree.png`）。

     - 在报告里放上图片，标出一个关键节点（比如第一个分裂点），写写它的分裂条件是什么意思。

  3. 加点自己的想法：

     - 给模型加一个特别的限制，比如：

       - 不让某个特征（比如“年级”或“价格”）出现在前两层分裂，写代码实现（可以用 `max_features` 或手动调整数据），并说明为什么。

       - 改一个样本的标签（比如把“是”改成“否”），看看决策树怎么变。

     - 在报告里写：

       - 不同设置（`max_depth`、`criterion`）对准确率有什么影响？

       - 你的限制有没有让模型更好解释？为什么？

- 提示：

  - 如果 graphviz 出问题，检查环境变量，或用 `plot_tree`。

  - 保存代码，报告里放关键片段（比如训练和画图部分）。

4. 评估模型并思考

- 做什么：

  - 用测试集评估模型，算这些指标：

    - 准确率（`accuracy_score`）

    - 混淆矩阵（`confusion_matrix`）

    - 选一个额外指标（比如精确率 `precision_score` 或召回率 `recall_score`）。

  - 在 PyCharm 里画一个图：

    - 如果是二分类，画 ROC 曲线（用 `roc_curve` 和 matplotlib）。

    - 或者画特征重要性图（用 `model.feature_importances_`）。

  - 在报告里回答：

    1. 你的模型有没有过拟合？怎么看出来的？如果有，提一个改进办法。

    2. 如果这个模型用在现实（比如预测活动参与或商品分类），可能会遇到什么问题？怎么解决？

    3. 如果数据量变成 10 倍，决策树会变好还是变差？为什么？

- 提示：

  - 保存图表为图片，放进报告。

  - 回答问题时结合你的数据集，写出自己的想法。

  常见问题解答

  - Q：自己设计数据集怎么开始？

    - A：用 Excel 列出特征和目标（像“是否参加”），填 100 条记录，或用 numpy.random 生成（老师会给示例）。保存为 CSV。

  - Q：下载的数据集不合适怎么办？

    - A：检查是否有分类目标和足够记录；如果不合适，换一个数据集，或改用选项1（自己设计）。

  - Q：画决策树失败怎么办？

    - A：检查 graphviz 环境变量，或用 `plot_tree`。如果还不行，提交代码和错误截图，说明尝试过程。

  - Q：怎么选超参数？

    - A：按要求试 `max_depth=3和5`、`criterion='gini'和'entropy'`，比较准确率，报告里写观察。
